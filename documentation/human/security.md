# Security

This is a public repository with a level-0 public information boundary. Only lawful public/open source material, synthetic fixtures, and generic engineering techniques belong here.

Do not commit credentials, cookies, private keys, session material, private source inventories, customer information, proprietary logic, FCI, CUI, classified information, or unrelated personal information. `SOLARI_API_KEY` and any gated-source credentials are operator-supplied through the environment. Acquired pages, uploaded documents, imported cases, XML, archives, generated parsers, and third-party data are untrusted inputs and must remain bounded and validated.

CI runs the repository's public-release scanner. That automated check does not replace the outstanding semantic public-release review immediately before submission or release.
